# Approved mockups (step 0.4.3)

These files are the approved screen mockups (decisions D-129 to D-131), exported from the Claude Design canvas "Jathag – Mockups 0.4.3" on 2026-11-26. They are a **visual and numeric reference only**: they use a canvas format (`<x-dc>`, `<sc-for>`, `{{…}}`, `renderVals()`) that does not run in Next.js and must not be imported or copied as code. Read them for layout, sizes, spacing, colours and wording; build real components as described in `docs/design/design-spec.md`, which wins where the two differ.

All birth data in them is the made-up reference birth R01 (Chennai, 14 Aug 1992, 6:45 AM IST) with real engine output as of 26 Nov 2026. `HomePhone.dc.html` was called `Main.dc.html` on the canvas. `SouthChart.dc.html` is mounted inside both chart pages.

Do not edit these files to change the design. Design changes are decided in the Project chat, made on the canvas, and exported here again.
