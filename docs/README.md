# docs

Product documents, prepared in the Claude Project (the source of truth) and mirrored here. Claude Code reads them but does not edit them.

- `product-brief.md` — the founder's original brief
- `requirements.md` — what to build, with requirement IDs (e.g. FR-CALC-03) and milestones
- `decisions-log.md` — every decision, its date and why
- `roadmap.md` — milestones v0.1 → v1.5 with numbered steps and "done when" conditions

Live build status is in `../PROGRESS.md`.
